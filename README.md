# Sharp — observe · remember · reason

A daily ~15-minute trainer for observation, memory for people and details, and honest "reading people" reasoning.

**Run it:** double-click `index.html` in File Explorer so it opens in Chrome or Edge. No install, no internet needed. (The Claude app's built-in preview can't load the scripts from a file; it needs a local server: `python -m http.server 8765` in this folder, then open http://localhost:8765.)
Or serve it: `python -m http.server 8765` in this folder, then open http://localhost:8765.

**Test it:** `npm test` (Node's built-in test runner; no dependencies).

Progress is saved in your browser's localStorage. Use Settings → Export backup now and then.

See `MORNING_REPORT.md` for what it is, why it's built this way, and the research behind it.
